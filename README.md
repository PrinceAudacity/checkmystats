# CheckMyStats

> A visual knowledge map connecting academic skills to career outcomes.

Built on the PathFinder architecture. CheckMyStats shows students
exactly where they are in their learning journey, where they can go, and
the precise path to get there.

## Stack

- **Frontend**: React + Vite + D3.js + Tailwind CSS
- **Backend**: Python + FastAPI + SQLAlchemy + SQLite/PostgreSQL
- **Containers**: Docker + Docker Compose
- **Deployment**: Render.com

## Quick Start
```bash
cp .env.example .env
docker-compose up --build
# In separate terminal:
docker-compose exec backend python -m seed.seed_math
```

Visit http://localhost:5173
